# Repository structure — jurisdiction folders

One folder per jurisdiction, named by lowercase postal code. Inside each jurisdiction folder, one subfolder per production (named by its request ID), holding the documents exactly as produced plus a `production-note.md`. Correspondence lives under `requests/<jurisdiction-code>/<request-id>/`; our own analysis lives only in `finding-aids/`.
