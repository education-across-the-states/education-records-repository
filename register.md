# The Register — Education Records Repository

The citable index of the collection, in two parts:

- **Part 1 — the Document Register:** every document held, the request that produced it, and when it arrived.
- **Part 2 — the Request Register:** every request filed under the project, agency by agency, and where it stands.

Register IDs are permanent and never reused. Citation form:

> Education Records Project, Register ID ERP-[XX]-[seq], [Document title], [Agency] production of [date received], Education Across the States. https://github.com/education-across-the-states/education-records-repository

A document counts as published only when its row exists in Part 1 **and** its file loads at the path shown.
