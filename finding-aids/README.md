# Finding Aids — our work product

Everything in this folder is **our analysis**, built from the public records filed in the jurisdiction folders of this repository: indexes, cross-state tables, red-flag scans, and comparisons. It is labeled as ours and is published for free use with attribution ("Education Records Project, Education Across the States").

Rules that govern this folder:

- **Documents are never altered.** Analysis lives here only. The records themselves are filed exactly as produced, in the jurisdiction folders.
- **Methodology is published with every comparison.** Rankings and cross-state tables are always normalized per-pupil or per-capita — never raw totals across jurisdictions of different sizes — and each carries its sources, denominators, caveats, and what would change the result. A ranking we cannot defend does not publish.
- **Spotlights run both ways.** Where a state or district dramatically outperforms, the finding aid says so and examines what is being done differently; where one falls far short, the documents get the same attention.

Finding aids are added as productions arrive and are entered in the [Document Register](../register.md) like everything else in the collection.
